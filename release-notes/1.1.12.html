Quota Display 1.1.12

  • Les diagnostics des refus Codex précisent l’étape, la méthode JSON-RPC, le code autorisé et une catégorie de cause filtrée. Les réponses HTTP de quotas Claude peuvent inclure leur statut réel.
  • Les causes inconnues restent explicitement inconnues. Aucun journal brut, message fournisseur, jeton, compte ou contenu de conversation n’est transmis.
  • Le choix « Partager les erreurs techniques », la limitation à quinze minutes et les préférences existantes sont conservés.

Les nouveaux champs nécessitent cette mise à jour sur le Mac source. Ils ne permettent pas de reconstituer les détails des erreurs anciennes. Aucun nouveau firmware n’est nécessaire.

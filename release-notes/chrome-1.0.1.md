Quota Display pour Chrome 1.0.1 affiche les crédits OpenAI Work/Codex et les crédits API Claude fournis par le Companion Mac 1.1.14.

- Crédits API Claude achetés et mensuels affichés séparément, avec montant accordé et expiration UTC.
- Soldes inconnus conservés comme non fournis; soldes Claude anciens identifiés par ≈.
- Affichage et résumé accessible mis à jour dans les cartes à deux fournisseurs et pleine largeur.

Connectez Claude Console sur le Mac source, puis actualisez l’extension. Les sessions OpenAI et Anthropic restent sur ce Mac. Les permissions de l’extension sont inchangées.

Le ZIP GitHub peut être chargé comme extension non empaquetée. La distribution automatique par le Chrome Web Store dépend de la validation de Google.

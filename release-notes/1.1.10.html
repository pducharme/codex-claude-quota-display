Quota Display 1.1.10

  • Claude ne fait plus de lecture ni de demande de connexion lorsqu’il est masqué à la fois dans la barre de menus et dans l’interface.
  • Si la connexion Claude est absente ou expirée, les lectures sont suspendues, même après un redémarrage. Le Companion propose une reconnexion et reprend les lectures après son succès.
  • Une source distante indique que la reconnexion doit se faire sur le Mac source.
  • Au démarrage, le pont attend l’actualisation de Claude Desktop lorsqu’il est autorisé, sans basculer vers un autre compte Claude Code.
  • Les lectures Codex et les requêtes réseau récupèrent mieux après un délai dépassé ou une interruption temporaire. Les tentatives restent limitées et les erreurs persistantes demeurent signalées.
  • Un échec ponctuel ne produit plus immédiatement une seconde alerte de quotas périmés lorsque les dernières données sont encore récentes.

Les préférences, clés API et connexions existantes sont conservées. Aucun nouveau firmware n’est nécessaire pour les mini-écrans.

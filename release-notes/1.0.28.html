Quota Display 1.0.28

  • Modifiez ou restaurez la clé API du Mac source dans Paramètres → API et connexions → Clé API de ce Mac… Le changement prend effet immédiatement.
  • La configuration API peut être copiée depuis un Companion client même si la source est hors ligne ou refuse sa clé.
  • L’installateur vérifie Python avant de modifier les fichiers. Si Python ou les outils de ligne de commande Apple ne sont pas prêts, il explique comment terminer leur installation.

En mode distant, mettez à jour le Mac source et les Companions clients. La source configurée, les clés et les réglages sont conservés. Aucun reflash du mini-écran n’est nécessaire.

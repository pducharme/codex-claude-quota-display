Quota Display 1.1.17 — crédits API mensuels OpenAI

  • Affiche les crédits API mensuels liés à l’abonnement ChatGPT, séparément des crédits Work/Codex : montant utilisé / réellement accordé en USD et date d’expiration UTC.
  • Pour les afficher, choisissez « Paramètres → API et connexions → Connexions → Connecter OpenAI Platform… » sur le Mac source, puis connectez-vous à l’organisation liée à votre abonnement.
  • Reprend le montant accordé par OpenAI : le premier versement peut être proratisé, sans présumer un solde de 200 $.
  • Actualise les crédits toutes les cinq minutes. Une donnée inconnue reste « — »; après quinze minutes sans lecture réussie, le dernier solde est marqué « ≈ ».
  • Partage les montants, dates et l’identifiant de l’organisation avec Chrome 1.0.4 et le firmware du 17 novembre 2026. La session OpenAI Platform reste dans le stockage WebKit du Mac source.

Le lecteur dépend de la réponse de facturation privée d’OpenAI Platform. Reconnectez la fenêtre si la session expire. Les crédits Claude et les préférences existantes sont conservés. Le firmware est fourni séparément; son installation sur les mini-écrans reste à effectuer.

Application universelle Intel et Apple Silicon, avec les signatures Developer ID et Sparkle existantes. Le paquet d’installation n’est pas notarié par Apple.

Quota Display peut désormais suivre Codex, Claude, Gemini et Grok directement dans Chrome, sans Companion Mac. Dans **Paramètres → API et connexions**, choisissez **Sessions web — sans Mac**, puis **Connecter** pour les services voulus. Vous pouvez fermer les onglets une fois la connexion établie. Les quotas sont actualisés toutes les cinq minutes tant que Chrome fonctionne.

Le tableau de bord reprend la présentation du Companion. La première page regroupe Codex et Claude, avec le forfait Claude Ultra lorsque le compte le fournit. La flèche ouvre Gemini (cinq heures et semaine) et Grok (requêtes restantes par mode). Les crédits API OpenAI et Claude disposent de connexions distinctes.

Le mode **Companion Mac** utilise toujours l’adresse et la clé de votre source. Le Companion 1.1.18 peut fournir les quatre services à Chrome et aux mini-écrans. Le mode autonome de Chrome concerne uniquement le navigateur.

Pour installer le ZIP joint, décompressez-le et sélectionnez le dossier contenant `manifest.json` dans **Charger l’extension non empaquetée** sur `chrome://extensions` en mode développeur. La distribution par le Chrome Web Store dépend de la validation de Google.

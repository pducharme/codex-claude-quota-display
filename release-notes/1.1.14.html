Quota Display 1.1.14 — crédits OpenAI et Claude

  • Affiche les crédits OpenAI Work/Codex restants, séparément des limites d’utilisation et des resets en banque.
  • Réutilise la session Claude Console du profil Chrome autorisé sur le Mac source pour lire les crédits API de l’organisation sélectionnée, après sélection du fichier Cookies et autorisation du trousseau.
  • Distingue les crédits API achetés, le crédit mensuel restant et accordé, les autres promotions et l’expiration en UTC.
  • Transmet les soldes aux Companions distants, à l’extension Chrome 1.0.1 et au firmware du 27 octobre 2026 par l’API existante.
  • Conserve les soldes inconnus comme non fournis et signale les crédits Claude qui n’ont plus été actualisés depuis quinze minutes.

Sur le Mac source, connectez Claude Console dans Chrome et sélectionnez l’organisation concernée. Ouvrez ensuite Paramètres → API et connexions → Connexions → Autoriser Claude Console via Chrome… Sélectionnez le fichier Cookies du profil dans le sélecteur macOS, puis autorisez Chrome Safe Storage si macOS le demande. Les cookies restent uniquement en mémoire sur ce Mac. Les clients ne reçoivent que les soldes et leur contexte d’organisation.

Les préférences, clés API, sources de quotas et autorisations existantes sont conservées. L’application universelle et les mises à jour Sparkle sont signées Developer ID. Le paquet d’installation n’est pas notarié par Apple.

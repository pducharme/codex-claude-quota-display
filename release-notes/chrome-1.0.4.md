Quota Display pour Chrome 1.0.4

Ajoute les crédits API mensuels OpenAI à la carte Codex : montant utilisé / réellement accordé en USD et date d’expiration UTC, séparément des crédits Work/Codex. Le premier versement peut être proratisé; aucun solde de 200 $ n’est présumé.

Installez le Companion Mac 1.1.17 sur le Mac source, puis choisissez **Paramètres → API et connexions → Connexions → Connecter OpenAI Platform…** et sélectionnez l’organisation liée à l’abonnement ChatGPT. L’extension reçoit les soldes par l’API du Mac; la session OpenAI Platform reste sur celui-ci.

Une donnée inconnue reste **—**. Après quinze minutes sans lecture réussie, le dernier solde est marqué **≈** et le résumé accessible indique de reconnecter OpenAI Platform sur le Mac source. L’adresse du Mac, la clé API et les préférences de l’extension sont conservées lors d’une mise à jour.

Le ZIP joint permet une installation manuelle. La distribution par le Chrome Web Store reste soumise à la validation de Google.

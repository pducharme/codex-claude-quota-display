Quota Display 1.0.21

  • Le menu Paramètres remplace Options et passe de 14 à 7 entrées pour une ouverture plus compacte.
  • Les réglages sont regroupés dans Affichage, API et connexions, Mini-écrans et Mises à jour.
  • Les options de fenêtre et d’icône se trouvent dans Affichage. L’actualisation des quotas reste directement accessible dans Paramètres.

Les réglages existants et la source API sont conservés. Aucun nouveau flash du mini-écran n’est nécessaire.

Quota Display 1.1.13

  • Corrige le format du flux de mises à jour qui pouvait bloquer Sparkle lors de la préparation puis de la reprise d’une installation.
  • Les métadonnées d’installation se relisent maintenant avec le décodage sécurisé de Sparkle, y compris après un redémarrage.
  • Les versions antérieures à 1.0.7 conservent une proposition d’installation manuelle ; les versions compatibles reçoivent l’archive signée.

Les préférences, clés API et sources de quotas existantes sont conservées. Une installation déjà bloquée peut nécessiter une récupération locale avant de reprendre les mises à jour.

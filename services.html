Modèles et connexions

GitHub, YouTube, Twitch et devises

Ces modèles lisent leurs données depuis le Mac source. Commencez par ajouter un modèle, renseignez Connecter cette page sous son aperçu, puis cliquez sur Vérifier les données. Cette lecture fonctionne avant de brancher un mini-écran.

Les exemples de l’aperçu servent à composer la page. Les valeurs lues dans Vérifier les données viennent du fournisseur; une connexion manquante apparaît explicitement.

Build et déploiement GitHub

  1. Saisissez le dépôt sous la forme propriétaire/projet.
  2. Indiquez une branche, ou laissez-la vide pour le dernier workflow de toutes les branches.
  3. Pour un dépôt public, vérifiez directement les données.
  4. Pour un dépôt privé, ouvrez Connexions, rubrique GitHub, et enregistrez un jeton donnant la lecture d’Actions sur ce dépôt.

La page montre le dernier workflow GitHub Actions et sa conclusion. Un workflow réussi ne prouve pas à lui seul la santé du site déployé. La lecture est limitée à une fois par minute. Permissions et API GitHub Actions.

Créateur YouTube

  1. Dans votre projet Google Cloud, activez YouTube Data API v3 et créez une clé restreinte à cette API.
  2. Dans Connexions, rubrique YouTube, enregistrez cette clé.
  3. Dans la page, indiquez le nom public @votreChaine ou son identifiant commençant par UC.
  4. Choisissez votre objectif d’abonnés et vérifiez les données.

La page affiche les abonnés publics, les vues de la chaîne, l’objectif et la dernière vidéo publiée. YouTube arrondit le nombre public d’abonnés : le compteur ne représente pas chaque abonnement individuel. Une valeur masquée reste indisponible. Les lectures sont espacées de cinq minutes. Documentation YouTube Data API.

Live et Twitch

  1. Créez une application dans la console développeur Twitch.
  2. Dans Connexions, rubrique Twitch, renseignez son Client ID et son secret.
  3. Dans la page Live / Twitch, indiquez le nom de la chaîne.
  4. Vérifiez les données, puis publiez.

Le Companion obtient et renouvelle un accès d’application pour lire l’état public du stream. Le modèle distingue une chaîne hors ligne d’un service indisponible; il affiche le titre, les spectateurs et la durée lorsqu’elle diffuse. Les lectures sont espacées de trente secondes. Accès d’application Twitch.

Cours et devises

Choisissez les devises de départ et d’arrivée, puis vérifiez les données. Aucun compte n’est nécessaire. Le taux correspond à une publication quotidienne, avec sa date et sa variation depuis la précédente. Il ne représente pas un prix de négociation en direct. Le Companion consulte Frankfurter au plus une fois par heure. Pour une cryptomonnaie, choisissez Bitcoin, Ether ou Solana dans À suivre, puis la devise d’arrivée. Le modèle affiche la cotation CoinGecko, sa variation sur 24 heures et son heure de publication en UTC. Les lectures sont espacées d’une minute; une cotation sans horodatage ou vieille de plus de dix minutes est refusée. Le modèle ne passe aucun ordre et n’accède à aucun portefeuille. Les actions boursières ne sont pas incluses.

Accès CoinGecko

L’accès public peut fonctionner sans clé, selon les limites du fournisseur. Pour utiliser votre accès Demo, ouvrez Connexions, rubrique CoinGecko, et enregistrez votre clé Demo. Le Companion l’envoie dans l’en-tête de la requête; elle n’apparaît jamais dans la page du mini-écran. Consultez la documentation CoinGecko pour créer cet accès et vérifier ses quotas.

Accès et erreurs

Les accès sont enregistrés dans le trousseau du Mac source. Ils ne font pas partie des pages envoyées aux écrans. Après l’enregistrement, cliquez sur Vérifier les données : l’enregistrement d’une clé ne garantit pas que le fournisseur l’acceptera. Si le quota est atteint, le Companion attend avant de réessayer; cliquer plusieurs fois ne contourne pas cette limite.

Installer et mettre à jour

Le Companion et le moteur des mini-écrans évoluent séparément. Une mise à jour du Companion seule ne remplace pas le firmware de l’écran.

Mettre à jour le Companion

Les versions publiées sont disponibles dans les releases GitHub. Installez le paquet macOS de la version voulue. Avec une source distante, mettez à jour le Mac source et le Mac qui ouvre le Designer.

Conservez l’adresse du Mac source, la clé de connexion et les horaires de veille. Une mise à jour ne doit pas transformer un Companion client en nouvelle source locale.

Première installation sur le mini-écran

Le moteur Designer concerne le LilyGO T-Display S3 Long, écran tactile 640 × 180. Une installation initiale par USB est nécessaire sur chaque appareil. Les modèles LilyGO portant un nom proche ne sont pas interchangeables.

Appareil déjà configuré : conserver la mémoire des réglages et le partitionnement existant. L’image application se place à 0x10000. Une image complète destinée à un appareil neuf peut effacer les réglages.

La release Designer et sa procédure matérielle finale ne sont pas encore publiées. Ne remplacez pas le firmware stable par un fichier prévu pour un autre modèle.

Après cette première installation

Les pages, les choix de polices et les valeurs arrivent par le réseau depuis le Companion. Vous n’avez plus à brancher l’USB pour modifier une page.

Une nouvelle capacité du moteur peut néanmoins demander une mise à jour du firmware. La mise à jour du moteur par Wi-Fi n’est pas encore livrée; les changements de pages par HTTP le sont.

Identifier les deux écrans

Dans le Designer, chaque écran porte les six derniers caractères de son adresse matérielle. Connectez les appareils un à un si vous avez besoin de repérer lequel est lequel, puis choisissez les destinataires de chaque publication.

Les pages classiques restent affichées tant que vous n’envoyez pas une nouvelle composition.

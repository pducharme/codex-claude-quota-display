Votre première page

Pour une première composition, commencez avec Quotas, Météo ou Focus. Ces modèles ne demandent pas de nouvelle connexion à un service externe dans le Designer.

1. Ouvrir le Designer

Dans le menu du Companion sur le Mac, choisissez Paramètres → Mini-écrans → Designer…. Si votre Companion utilise un autre Mac comme source, le Designer s’ouvre sur ce Mac source.

Les deux Macs doivent disposer d’une version compatible. Une source trop ancienne peut afficher une erreur de page introuvable. Voir l’installation.

2. Choisir un modèle

Cliquez sur Ajouter, au-dessus de vos pages. Recherchez un usage ou choisissez une proposition dans la galerie. Lisez les prérequis indiqués avant de choisir un service connecté.

La page apparaît dans la liste de gauche. Son aperçu, au centre, utilise des données d’exemple. Elles vous aident à composer; elles ne prouvent pas que le service est connecté.

3. Personnaliser

Changez le nom, la police et les couleurs dans le panneau de droite. Cliquez sur un élément pour modifier son texte. Déplacez-le dans l’aperçu ou ajustez sa position dans les réglages.

Pour Météo, indiquez la ville. Pour un modèle Home Assistant, choisissez les appareils sous l’aperçu après avoir configuré la connexion.

4. Envoyer

Cochez l’écran destinataire, puis cliquez sur Envoyer aux écrans. Attendez Publication appliquée : ce message indique que le firmware a effectivement affiché la composition.

Si aucun écran n’est proposé, votre composition peut être préparée, mais le nouveau moteur doit être installé sur le mini-écran avant le premier envoi. Voir les états de publication.

Vos modifications restent dans la fenêtre tant qu’elles ne sont pas envoyées. Publiez avant de fermer le Designer; un avertissement signale les modifications non envoyées.

Ces deux modèles concernent le Mac source, celui qui collecte les données pour vos écrans. Si votre Companion utilise un autre Mac comme source, les statistiques et les commandes concernent cet autre Mac.

Statistiques de l’ordinateur

Ajoutez Stats ordinateur, puis cliquez sur Vérifier les données. Aucun compte n’est requis. Vous verrez l’utilisation du processeur, la mémoire utilisée et les débits réseau en réception et en envoi. Le premier débit reste vide jusqu’à la seconde mesure. La collecte se fait toutes les dix secondes.

Les débits concernent les interfaces réseau physiques du Mac. Une donnée trop ancienne disparaît au lieu de rester affichée comme actuelle.

Volume et silence

Ajoutez Contrôles du Mac. Les boutons Vol −, Muet et Vol + commandent la sortie audio actuellement sélectionnée sur le Mac source. Chaque pas de volume vaut cinq points de pourcentage.

Certaines sorties HDMI, numériques ou externes imposent un volume fixe. Le modèle indique alors Fixe et refuse la commande; réglez le volume sur le périphérique correspondant.

Lecture et raccourcis

  1. Sur le Mac source, créez votre commande dans l’application Raccourcis. Pour la lecture, préparez par exemple un raccourci Lecture / pause.
  2. Exécutez-le une fois sur ce Mac pour vérifier les éventuelles autorisations.
  3. Dans le Designer, cliquez sur Actualiser les raccourcis du Mac.
  4. Sélectionnez le raccourci Lecture / pause, puis éventuellement un autre raccourci pour le bouton Lancer.
  5. Publiez la page et utilisez les boutons tactiles.

Choisissez des raccourcis sans demande de saisie : le mini-écran ne peut pas répondre à une boîte de dialogue du Mac. Une commande qui dépasse le délai de confirmation n’est pas répétée automatiquement. Vérifiez son résultat sur le Mac avant de relancer une action.

Le Designer propose les noms des raccourcis existants. Il ne demande pas de commande Terminal. Fonctionnement des raccourcis macOS.

1.1.8 — alertes Avion

La release 1.1.8 fournit le Companion et le firmware avec page Avion animée, texte complet et durée réglable de 0,1 seconde à 24 heures, avec 3 secondes par défaut. Les changements de durée suivants passent par Wi-Fi. Le firmware a été installé sur un écran de référence : réglages préservés, tactile et composition confirmés. Les règles de durée, sortie de zone et suppression des doublons ont été testées en logiciel; elles ne constituent pas une observation chronométrée de vols réels sur le matériel.

Historique de validation au 21 septembre 2026. Les fonctionnalités développées ne deviennent pas automatiquement des fonctionnalités publiées.

Firmware stable

La release firmware-2026.09.20 contient la désactivation de la DEL verte et les réglages tactiles existants. Le moteur Designer n’est pas inclus dans cette release stable.

Designer en préparation

Le travail est suivi dans la pull request Designer. Le Companion 1.1.0 est maintenant installé sur les deux Macs du projet, dont le Mac source, avec les 26 usages et les deux modèles supplémentaires Horloge et Page libre. Le catalogue complet a été vérifié dans le Companion connecté à sa source. Le premier mini-écran a reçu le moteur Designer; le partitionnement et les réglages ont été vérifiés identiques avant et après cette installation. L’horloge en JetBrains Mono, le balayage vers Focus et le démarrage tactile du minuteur ont été confirmés sur cet appareil, alimenté par un chargeur USB. Les publications ont été accusées par l’écran après affichage. Les pochettes musicales, les cycles Focus, la pluie à venir et les cours crypto sont également implémentés. Les essais avec les appareils et comptes réels restent distincts de ces vérifications logicielles.

Les tests logiciels vérifient les documents, l’authentification, les publications ciblées, le retour arrière, les données périmées et la sélection des vols. La présence d’une intégration dans le code n’atteste pas un essai avec le compte ou l’appareil réel.

Avant la livraison complète

  • Terminer les essais des intégrations avec les comptes et appareils réels disponibles.
  • Vérifier le Designer par son interface, puis ses commandes sur le matériel.
  • Installer le nouveau firmware sur le deuxième écran en conservant ses réglages, puis terminer les essais sur les deux appareils.
  • Vérifier le tactile, les polices, le cache au redémarrage, la bascule avion, le retour à la page et la veille.
  • Publier les fichiers de release et actualiser ce guide avec les versions validées.

Le catalogue et cette page seront mis à jour au fil des livraisons, sans présenter les modèles restants comme terminés.

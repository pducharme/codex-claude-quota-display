Le Mac prépare, l’écran affiche

Le Companion récupère les données des services et les transmet à vos mini-écrans. Les pages se modifient par le réseau : après l’installation initiale du moteur, changer une disposition, une police ou un modèle ne demande pas de reprogrammer l’écran.

Le Mac source doit rester allumé et accessible. Les écrans conservent la dernière composition reçue et signalent lorsque les valeurs ne sont plus actualisées.

Un usage pour chaque endroit

Un écran de bureau peut afficher vos quotas, votre concentration ou une réunion. Dans la maison, il peut présenter une pièce Sonos ou les données de capteurs déjà connectés. Dans le ciel affiche un avion qui passe dans une zone choisie et peut temporairement remplacer la page active.

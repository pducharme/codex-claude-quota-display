Home Assistant relie les appareils de votre maison au Companion. Les modèles proposent des sélecteurs par nom : vous n’avez pas à écrire de code ni de chemin de données.

Cette connexion est implémentée dans la branche de développement. Elle n’a pas encore été livrée dans une release publique ni vérifiée avec les appareils personnels de l’utilisateur.

Avant de connecter

Les enceintes, calendriers, capteurs ou imprimantes doivent déjà fonctionner dans Home Assistant. Le Companion ne remplace pas leur intégration : il lit les états disponibles et envoie les commandes des modèles.

Le Mac source doit pouvoir rejoindre l’adresse de Home Assistant. Un appareil uniquement disponible depuis un autre réseau ne sera pas accessible sans connexion réseau adaptée.

Connecter une fois

  1. Dans Home Assistant, ouvrez votre profil, puis la rubrique Sécurité.
  2. Créez un jeton d’accès de longue durée nommé, par exemple, « Quota Display ».
  3. Dans le Designer, cliquez sur Connexions.
  4. Saisissez l’adresse de base de Home Assistant, avec son port si nécessaire, et le jeton.
  5. Cliquez sur Connecter Home Assistant. La connexion est vérifiée avant son enregistrement.

Le jeton est conservé dans le trousseau du Mac source. Il n’est pas inclus dans les compositions, le guide public ou les messages destinés aux mini-écrans.

Le Designer suit le réseau de confiance déjà utilisé par Companion. Évitez d’ouvrir son port sur Internet; consultez Données et confidentialité.

Choisir les appareils

Ajoutez un modèle, puis utilisez Connecter cette page, sous l’aperçu. Chaque liste propose les types d’appareils appropriés. Une page Air intérieur attend des capteurs; une page Sonos attend une entité de lecture multimédia.

Si vous venez d’ajouter un appareil, ouvrez Connexions et cliquez sur Actualiser les appareils. Une ancienne sélection absente apparaît comme introuvable au lieu d’être remplacée silencieusement.

Configurer Sonos

Ajoutez vos enceintes avec l’intégration Sonos de Home Assistant. Dans le modèle Télécommande Sonos, sélectionnez la pièce à contrôler.

La page propose le titre, l’artiste, le volume, précédent, lecture/pause, suivant, volume −/+, et muet. Les commandes agissent sur la pièce sélectionnée et les groupes tels qu’ils existent dans Home Assistant.

Pour un favori, activez le capteur Sonos Favorites dans Home Assistant, puis sélectionnez-le dans le Designer. Cliquez sur Actualiser les appareils et favoris, choisissez votre favori et publiez. Le bouton Favori du mini-écran lance uniquement ce choix; un favori supprimé ne sera pas remplacé par un autre.

Capteurs, scènes et services

Les modèles Air, Énergie, Véhicule électrique, Homelab, Impression 3D et Maison à surveiller lisent les entités que vous sélectionnez. Les unités viennent de Home Assistant. Pour une jauge, choisissez une valeur en pourcentage.

Scènes de la maison permet d’associer trois scènes aux boutons. Lessive terminée permet d’acquitter localement le rappel; cela ne remet pas le lave-linge à zéro. Un changement d’état réactive le rappel.

Les départs de transport et les colis nécessitent une intégration existante qui fournit les informations voulues sous forme de capteurs. Ce n’est pas une compatibilité universelle avec tous les réseaux de transport et transporteurs.

Configurer Spotify

  1. Configurez l’intégration officielle Spotify dans Home Assistant. Elle nécessite un compte Premium et une application Spotify Developer. L’autorisation du compte se fait dans Home Assistant.
  2. Lancez Spotify sur l’appareil de lecture souhaité pour qu’il apparaisse dans Spotify Connect.
  3. Ajoutez Télécommande Spotify dans le Designer et sélectionnez votre compte dans la liste.
  4. Cliquez sur Actualiser les appareils et favoris, puis choisissez l’appareil Spotify Connect.
  5. Vérifiez les données et publiez. Le bouton Appareil du mini-écran sélectionne la sortie choisie; les autres boutons contrôlent la lecture active.

Les informations suivent les mises à jour de Home Assistant; elles ne changent pas forcément à la seconde près. Une enceinte Sonos se configure avec le modèle Sonos, car l’API Spotify officielle ne prend pas en charge ce type de sortie. La pochette est transmise au mini-écran sous forme d’image compacte de 32 × 32 pixels, avec ses proportions conservées. L’aperçu du Designer utilise un disque fictif; la pochette du morceau apparaît sur le mini-écran après connexion. Si elle manque, l’écran indique Sans image. Les adresses d’images et les accès aux comptes restent sur le Mac.

Suivre une équipe

Installez et configurez TeamTracker dans Home Assistant. Ajoutez Score sportif et sélectionnez le capteur de votre équipe. Le modèle distingue le prochain match, un match en cours, un résultat final et l’absence de rencontre. Pendant un match, un score vieux de plus de deux minutes est masqué.

Rappels de la maison

Le modèle Véhicule électrique propose un seuil de batterie pour rappeler le branchement. Sélectionnez un capteur binaire de branchement dont « off » signifie débranché. Le rappel apparaît sous le seuil choisi, jamais avec une batterie inconnue.

Dans Maison à surveiller et Lessive terminée, Vu, merci acquitte le rappel de cet écran. Si un des capteurs sélectionnés change d’état, le rappel revient. Pour la lessive, la durée affichée mesure le temps depuis le changement du capteur; choisissez un capteur qui représente bien l’état du cycle.

Données et confidentialité

Les pages et leurs connexions sont gérées par le Mac source. Ce site de documentation est public et statique : il ne se connecte pas à votre Companion, à vos comptes ou à votre domicile.

Où restent les accès

Les identifiants des fournisseurs restent sur le Mac. Les accès Home Assistant, GitHub, YouTube, Twitch et CoinGecko sont enregistrés dans le trousseau; les compositions contiennent les appareils sélectionnés, sans leur jeton d’accès.

Les mini-écrans reçoivent les informations nécessaires à l’affichage. Ils utilisent une clé de connexion au Companion, distincte des accès aux fournisseurs.

Réseau et accès au Designer

Le Designer s’ouvre depuis le Companion avec son authentification. La session web expire et les modifications sont protégées contre les requêtes provenant d’autres sites. Une rotation de la clé révoque les anciennes sessions.

La liaison historique au Companion utilise HTTP sur le réseau local. HTTP n’assure pas le chiffrement du trafic : utilisez un réseau de confiance et n’exposez pas le port du Companion à Internet. HTTPS est accepté pour la connexion Home Assistant lorsque votre instance le propose.

Données envoyées aux services

  • Météo : ville ou zone nécessaire à la prévision.
  • Dans le ciel : coordonnées et rayon de recherche, puis identifiants nécessaires à l’enrichissement du vol.
  • Home Assistant : requêtes d’états, pochettes musicales et commandes sur les appareils que vous avez choisis.
  • GitHub : nom du dépôt et branche demandée.
  • YouTube et Twitch : identifiant de la chaîne à suivre et accès API associé.
  • Frankfurter et CoinGecko : devises ou cryptoactif demandés, avec la clé Demo si vous en avez enregistré une.

La connexion Home Assistant refuse les redirections pour éviter de transmettre le jeton à une adresse différente.

Ce qui est public sur GitHub

Le code, le guide, les exemples fictifs et les fichiers de release sont publics. Vos jetons, votre zone personnelle, vos compositions enregistrées et la liste de vos appareils n’ont pas à être publiés.

Pour révoquer Home Assistant, supprimez le jeton correspondant dans votre profil Home Assistant. L’accès du Companion cesse alors de fonctionner; un nouveau jeton peut être saisi depuis Connexions.
